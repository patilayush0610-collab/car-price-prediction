# car-price-prediction
A Flask-based Machine Learning project that predicts used car prices using Linear Regression trained on real dataset features like year and kilometers driven.
# 🚗 Car Price Prediction Web App

This is a Machine Learning based web application that predicts the price of a used car based on its features like year and kilometers driven.

---

## 📌 Project Overview
This project uses Linear Regression algorithm to predict car prices. It is built using Flask for backend and HTML/CSS for frontend.

---

## ⚙️ Technologies Used
- Python
- Flask
- Pandas
- Scikit-learn
- HTML
- CSS

---

## 🧠 Machine Learning Model
- Algorithm: Linear Regression  
- Input Features: Year, KMs Driven  
- Output: Predicted Car Price  

---

## 🚀 How to Run

1. Clone the repository
2. Install requirements
3. Run `train_model.py`
4. Run `application.py`
5. Open browser: `http://127.0.0.1:5000`

---

## 📸 Project Features
- Clean UI Dashboard
- Real-time price prediction
- Simple and fast ML model
